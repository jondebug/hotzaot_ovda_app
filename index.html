מחיקת כל הנתונים

פעולה זו תמחק לצמיתות את כל התנועות מהאחסון המקומי, ולא ניתן לבטלה.
כדי לאשר, הקלד/י מחק בשדה הבא:

סנכרון משפחתי

האפליקציה מסנכרנת את כל התנועות בענן באמצעות GitHub כך שכל בני המשפחה רואים את אותם הנתונים בכל מכשיר. להתחברות הדביקו Personal Access Token בעל הרשאת Contents על המאגר. הטוקן נשמר רק במכשיר הזה ולא נשלח לשום מקום אחר חוץ מ‑GitHub.

איך מייצרים טוקן? (לראש המשפחה)
  1. היכנסו ל-GitHub Settings → Personal Access Tokens (Fine-grained)
  2. Repository access → Only select repositories → jondebug/hotzaot_ovda_app
  3. Repository permissions → Contents → Read and write
  4. שמרו והעתיקו את הטוקן (מתחיל ב‑github_pat_)
  5. שתפו עם בני המשפחה דרך ערוץ פרטי
